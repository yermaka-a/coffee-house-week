# Coffee House ☕️🍰

Добро пожаловать в **Coffee House** — ваш виртуальный кафе, где вы можете выбрать идеальный кофе и десерт к нему! Этот сайт создан с использованием нативного JavaScript и SCSS, предоставляя пользователям интуитивно понятный интерфейс для выбора напитков и сладостей. Также на сайте доступно видео, загруженное из статических файлов, для создания уютной атмосферы.

## Описание проекта

Coffee House — это веб-сайт, который предлагает пользователям возможность выбирать различные виды кофе и десертов. Сайт включает в себя:

- Удобный интерфейс для выбора меню
- Возможность просматривать информацию о каждом напитке и десерте
- Встроенное видео, которое создает атмосферу кафе

## Функциональность 🌟

- Выбор различных видов кофе и десертов
- Интерактивный интерфейс с подробной информацией о каждом продукте
- Воспроизведение видео из статических файлов с помощью HTML-тега `<video>`

## Технологии 🛠️

- **HTML**: Структура сайта
- **SCSS**: Стилизация и адаптивный дизайн
- **JavaScript**: Логика и функциональность сайта
- **HTML `<video>`**: Встраивание видео для создания атмосферы

## Использование 💻
После установки вы можете открыть index.html в вашем браузере, чтобы начать использовать сайт. Вы сможете:

Выбирать кофе и десерты
Смотреть видео, загруженное из статических файлов
### Примечание о видео
В проекте используется HTML-тег <video> для встраивания видео. Убедитесь, что видеофайлы находятся в правильной директории, чтобы они отображались корректно.
```html
<video controls>
    <source src="path/to/video.mp4" type="video/mp4">
    Ваш браузер не поддерживает видео.
</video>
```
